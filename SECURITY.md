# Security Policy

## Supported Versions

Security fixes are currently provided for the latest main branch and current release line.

| Version | Supported |
|---|---|
| 0.1.x | Yes |
| < 0.1.0 | No |

## Reporting A Vulnerability

If you discover a security issue, do not open a public issue.

Report privately to the maintainers with:

- A clear description of the issue.
- Reproduction steps and prerequisites.
- Impact assessment (what can be accessed or executed).
- Suggested remediation if available.

Until a dedicated security mailbox is configured, report through the repository owner using private communication channels.

## Response Expectations

- Initial acknowledgement target: within 3 business days.
- Triage and severity assessment target: within 7 business days.
- Fix timeline depends on severity, complexity, and release constraints.

## Scope

This policy applies to:

- `machine-agent/`
- `controller-extension/`
- `installer/`
- Build/release configuration in CI

## Disclosure Guidance

- Coordinate disclosure with maintainers.
- Avoid publishing exploit details before a fix or mitigation is available.
- Provide enough technical detail for reliable reproduction and validation.
